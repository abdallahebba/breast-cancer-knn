# Breast Cancer Detection App

A Machine Learning web app that predicts whether a breast tumor is:

- Malignant
- Benign

Built using:
- Python
- Streamlit
- Scikit-learn
- KNN Classifier

## Features
- User inputs tumor features
- Model predicts tumor type
- Simple interactive UI

## Model Accuracy
97%

## Run Locally

```bash
streamlit run app.py
